# Bank-Management-System

Mini project



\# ATM Simulator System



A Java-based ATM Simulator System that provides basic banking operations through a graphical user interface.



\## Features

\- User registration and login

\- Balance enquiry

\- Cash deposit and withdrawal

\- Fast cash

\- Mini statement

\- PIN management

\- UPI payment



\## Technologies Used

\- Java

\- Java Swing and AWT

\- MySQL

\- JDBC



\## How to Run

1\. Open the project in Apache NetBeans.

2\. Configure the MySQL database connection in the connection classes.

3\. Add the required MySQL JDBC driver.

4\. Run the main application class.
