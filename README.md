# ATM Simulator System

A Java-based ATM Simulator System developed as a mini project to simulate basic banking operations through a graphical user interface.

## Project Overview

The ATM Simulator System is designed to provide users with a simple banking experience. It allows users to create an account, log in, and perform essential banking operations such as depositing money, withdrawing cash, checking account balances, and viewing transaction history.

The application uses Java Swing and AWT for the graphical user interface and MySQL for database management.

## Features

- User Registration
- User Login
- Balance Enquiry
- Cash Deposit
- Cash Withdrawal
- Fast Cash
- Mini Statement
- PIN Management
- UPI Payment

## Technologies Used

| Technology | Purpose |
|---|---|
| Java | Core application development |
| Java Swing | Graphical user interface |
| Java AWT | GUI components and event handling |
| MySQL | Database management |
| JDBC | Database connectivity |

## Requirements

- JDK 17 or later
- MySQL Server
- Apache NetBeans IDE
- MySQL JDBC Driver

## How to Run

1. Clone or download this repository.
2. Open Apache NetBeans IDE.
3. Import the project into NetBeans.
4. Create and configure the required MySQL database.
5. Update the database connection details in the connection classes.
6. Add the MySQL JDBC driver to the project.
7. Run the main application class.


## Project Objective

The main objective of this project is to understand Java-based desktop application development, GUI programming, database connectivity using JDBC, and the implementation of basic banking operations.
